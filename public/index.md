# Nosana

**Instant GPU rental at scale for AI and high-performance workloads.** An
open-source GPU cloud built for AI and high-performance workloads. Run on
demand with flexible pricing and up to 6× lower costs.

## Two ways to use it

**Run GPU workloads on demand.** Scale as needed with on-demand GPU workloads
that grow with your performance needs. → [Run GPU workloads](https://nosana.com/gpu-workloads/)

**Turn your GPUs into profit.** Share idle GPU capacity and earn by running
workloads on your hardware, with built-in security. → [Provide GPUs](https://nosana.com/gpu-providers/)

## What it is for

Nosana provides on-demand, distributed GPU compute with a simple way to run and
scale AI — including agentic and high-performance workloads — from training and
fine-tuning to inference, rendering and simulation.

Typical uses: serving an open-weights LLM behind an HTTPS endpoint, running a
long-lived GPU service with replicas, and batch GPU work such as rendering,
fine-tuning or benchmarking.

It is not intended for CPU-only batch work, general web hosting, persistent
databases, or anything requiring storage that survives a deployment.
